## Validation Strategy

### Recommended: Stratified 5-Fold CV

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]
```

### Why Stratified?

- Target is imbalanced (~30% positive)
- Stratification ensures each fold has similar class distribution
- Prevents folds with no positive samples

### Seed Sensitivity

Run multiple seeds to check stability:
```python

    skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=seed)

```
