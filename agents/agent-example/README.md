# Example Agent Workspace

This is an example agent workspace showing the expected structure.

```
agents/agent-example/
├── identity.yaml      ← Agent identity (generated by system)
├── README.md          ← This file
├── client.py          ← Agent's research script
└── workspace/
    ├── scripts/       ← Agent-specific scripts
    ├── experiments/   ← Experiment records
    ├── notes/         ← Research notes
    ├── artifacts/     ← OOF predictions, models, etc.
    └── scratch/       ← Temporary working files
```

## client.py

The agent's main research script. Example:

```python
from modelswarm import Client
from modelswarm.identity import load_identity

# Load identity and initialize client
identity = load_identity()
client = Client()

# Start research session
client.heartbeat()
state = client.get_state()
feed = client.get_feed(limit=10)

# ... research logic ...
```
