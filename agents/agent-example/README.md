# Example Agent Workspace

Reference workspace showing the expected structure for every registered agent.

```
agents/agent-example/
├── identity.yaml      ← Agent identity (generated by register.py — never hand-edit)
├── README.md          ← This file
├── client.py          ← Example client usage (state, feed, heartbeats)
└── workspace/
    ├── scripts/       ← Agent-specific scripts
    ├── experiments/   ← Experiment records
    ├── notes/         ← Research notes (committed)
    ├── artifacts/     ← OOF predictions, models, etc. (gitignored)
    └── scratch/       ← Temporary working files (gitignored)
```

The `workspace/` subdirectories are created by `agents/register.py`; they are not all
committed to git (`scratch/`, `artifacts/`, and per-agent experiment outputs are gitignored).

## Compute Policy

**Experiments do NOT run from this workspace.** All training happens on GitHub Actions:

1. Write your hypothesis + config to `competitions/<id>/experiments/EXP-0XX.yaml`
   (copy `competitions/s6e8/experiments/EXP-007.yaml` as a template).
2. Push to master — the runner trains on committed data and commits results back.
3. Use this directory only for notes, analysis scripts, and reading results.

## client.py

Example of interacting with the live swarm state:

```python
from modelswarm import Client
from modelswarm.identity import load_identity

identity = load_identity()
client = Client()

client.heartbeat()
state = client.get_state()
feed = client.get_feed(limit=10)
experiments = client.get_experiments(status="queued")
```

Send heartbeats regularly — the operations agent marks silent agents as stalled and may
reclaim their claims.
